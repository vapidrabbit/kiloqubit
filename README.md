This is a dense, all to all, max-cut problem OpenQASM 3 code. I'm publishing this so that hopefully others with a kiloqubit QPU will be able to test it.

The context of this is essentially that 1 product maps to 1 node, and 1 node maps to 1 qubit. The prices of the products over time influence numbers in this when the qubits are entangled. 

Let's say you want to diversify what products you want on the front page using a max-cut problem. You can choose from bucket A or bucket B.
